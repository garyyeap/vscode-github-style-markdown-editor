# Change Log

## 1.0.0 — November 18, 2026
First release of GitHub Style Markdown Editor, a fork of [GitHub Markdown Preview](https://github.com/mjbvz/vscode-github-markdown-preview) by Matt Bierner.

- WYSIWYG markdown editor that renders files the way GitHub does.
- Bundled GitHub themes: light, dark, dark dimmed, high contrast and colorblind, with `githubStyleMarkdownEditor.*` settings.
- Read only, edit and markdown source modes, remembered per file.
- `/` block menu, drag handles, tables, task lists, code blocks with GitHub colors, live mermaid diagrams and KaTeX math.
- Raw HTML such as `<p align="center">`, badges and `<kbd>` is rendered like on GitHub and can be edited by clicking it.
- Pasted images are saved next to the markdown file.
- No longer an extension pack: the four Markdown preview extensions are not installed anymore.
